# ADA Digital Accessibility: GitHub Copilot + Accessibility Scanner

---

## The Problem

**ADA Title II** now requires all state and local government websites to meet **WCAG 2.1 Level AA** — 50 success criteria covering perceivable, operable, understandable, and robust web content.

**Deadline: April 24, 2026** (entities with 50,000+ population — that's Hawaii)

Non-compliance means DOJ complaints, private lawsuits, civil penalties up to **$150,000**, and mandatory court-monitored remediation.

---

## The Forcing Function

The DOJ finalized this rule on **April 24, 2024** giving states just 2 years. Every public-facing website, online portal, PDF library, and mobile app must comply — including all department sites managed by ETS.

Hawaii ETS manages a **standard WordPress State Theme** used across departments. One theme with accessibility issues means every department site fails.

---

## The Old Way

1. **Manual audit** — hire consultants ($50K–$200K) to crawl every page with screen readers and contrast checkers
2. **Spreadsheet of findings** — hundreds of issues across dozens of pages, documented in a report
3. **Developer triage** — engineers manually interpret each finding, look up WCAG rules, write fixes
4. **Re-test** — pay for another audit to verify each fix
5. **Repeat** — new content breaks accessibility, start over next quarter

Slow, expensive, and doesn't scale. A typical state site remediation takes **6–12 months**.

---

## The New Way: GitHub Accessibility Scanner + Copilot



**What used to take months now takes days.** And it stays compliant as new content is published.
